# PULSE — a new film, not a reskin

Brief: trading topic, neon purple + black, Apple-like restrained typography, independent SaaS-animation research. Product is a fictional trading journal, not an existing service. 24 seconds, 9:16, 60 fps.

Palette: #050407 black, #A862FF violet, #D2ADFF soft lavender, #F5F3FF white. These are derived from the user's explicit color request. Inter 500/600 approximates the requested neutral grotesk direction; it is not Apple's proprietary font.

One argument: the next entry can start with a recorded reason. Show an illustrative journal being used. No promises of financial returns.

0–3: dimensional candles, camera orbit, title.
3–7: one candle becomes a journal entry; fields fill and the save action lands.
7–10: journal entries organize and one floats forward.
10–14: the selected trade becomes a pattern view, filter and bar reveal.
14–18: the chart leads to a next-trade plan and a risk control.
18–21: UI recedes into the pulse symbol.
21–24: brand + short closing phrase.

Motion: continuous shared world, authored camera path, 3D specular light, sequential UI causality, short asymmetrical settles. Typography reveals by line, no letter scattering, no permanent glow. Original synthesized sound bed and click/transition cues; no previous video footage or audio.

## Reference research

Search query `animation SaaS` / `saas remotion video`, GitHub web search.

- https://github.com/codeverbojan/remotion-cinematic — README and the 61.08-second demo-preview.gif were accessed; GIF sampled at 1s and 5s. The GIF is an editor demonstration, not a complete finished product film. Useful observation: windows preserve identity across layout changes; cursor and camera move to the active control.
- https://github.com/noamdorr/saas-product-demo-video — public README and reference atlas read. Useful method: input → visible response, focused interaction shots, examine transition neighborhoods, not only clean keyframes. Referenced external films were not viewed.
- https://github.com/motiondivision/motion — public API overview read for spring/layout motion vocabulary. Runtime implementation here remains frame-driven Remotion.
- YouTube search (`animation SaaS`) and Dribbble (`saas-animation`) were attempted but both were denied by the cloud network proxy (403). No claim of having viewed those results.

All visuals and sound in this film are authored locally. No reference assets or code copied into the deliverable.
